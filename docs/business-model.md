# ONE EIGHTの事業モデル

## 現在の案内方針（2026年11月26日更新）

現在案内するサービスは「Webサイト・アプリ開発」の1つです。コンサルは、所有者の最新指示により、いったんサイト上の案内から外します。過去のコンサル料金・返金制度を、現在申し込める別サービスとして紹介しません。変更の経緯は [検証記録](validation.md) に残し、この文書では最新のモデルを説明します。

主な対象は、地域の小さな小売店です。既存の飲食店・美容院・小売店・ネイルサロン・ヨガ教室という5業種の紹介は維持します。対象としての紹介であり、導入実績や顧客一覧として扱いません。他業種を対象外にする条件も追加しません。

表現・デザインは [デザインとコンテンツの考え方](design-and-content.md) を参照してください。

## Webサイト・アプリ開発

最優先で伝えるのは、**「ほかの契約はありません」・月額10,000円（税込）・初期費用0円**という所有者の方針です。トップでは「ほかの契約はありません」を先頭に置き、月額を大きく、初期費用0円を太字で示します。この説明の近くに、**データベースのアップグレード時は別途月額3,000円（税込）、2か月目以降のアップグレード時は合計月額13,000円（税込）**を明記します。

| 項目 | 確認済みの案内 |
| --- | --- |
| サービス | お店専用のWebサイト・アプリ開発 |
| 初期費用 | 0円 |
| お試し | 基本プランは0円で1か月お試し。初月の基本月額料金は0円 |
| 基本月額料金 | 2か月目から10,000円（税込） |
| ほかの契約 | 「ほかの契約はありません」と案内する |
| DBアップグレード | アップグレード時に別途月額3,000円（税込） |
| 2か月目以降のアップグレード時の合計月額 | 基本月額10,000円＋DB月額3,000円＝13,000円（税込） |

「0円」は初期費用と初月の基本月額料金に関する説明です。2か月目以降の基本月額料金、DBアップグレード時の追加月額料金を近接して示し、無期限無料や「追加費用が一切かからない」という説明にはしません。

「ほかの契約はありません」という訴求を、無料解約、最低利用期間なし、自動更新なし、無制限修正など、指示されていない条件へ広げません。制作する内容、基本月額に含まれる対応範囲、お試しの開始日、継続・解約の方法は、これまでどおり利用前の確認事項です。

## データベースのアップグレード

通常の基本月額料金と、アップグレード時の追加料金を区別します。「月額10,000円（税込）」だけで料金説明を終えず、その近くに「DBアップグレード時は別途月額3,000円（税込）、2か月目以降のアップグレード時は合計月額13,000円（税込）」を示します。

アップグレードが必要になる具体的な基準、開始時点、容量や利用件数の上限は、今回の指示では確定していません。自動アップグレードや無制限利用、アップグレード費用の初月無料などを根拠なく追加しません。初月のお試しは、初期費用と基本月額料金が0円という確認済みの範囲で説明します。

## 事業の姿勢

ヒアリングで店舗固有の困りごとを聞き、店舗に合うWebサイトやアプリを考えます。相談の入口は無料ヒアリングです。AI／Codexと共通の仕組みを活用しながら、お店に必要な部分を調整し、制作から運用・改善まで取り組みます。

実家の和菓子屋という接点を課題理解の起点とし、学生としての柔軟さを大切にします。支援実績はこれからであり、導入件数・成功事例・改善数値や、存在しない法人格・人物プロフィールを創作しません。

## 運営上の検討事項

以下は運営設計の論点であり、新たな公開条件や顧客への約束ではありません。

- **初月終了時の採算**：標準構成では初期費用・初月の基本月額料金が0円です。制作・対応の範囲と継続率を踏まえて採算を確認します。新しい契約条件を追加するものではありません。
- **基本月額での対応範囲**：制作、運用・改善の範囲を事前に揃えます。未合意の即時対応や無制限修正を約束しません。
- **DBアップグレードの案内**：必要性、適用時点、追加月額3,000円（税込）と合計月額13,000円（税込・2か月目以降のアップグレード時）を利用者が理解できるよう整理します。

料金・条件の参照元は `src/data/site.ts` です。サイトの本文・料金表示・FAQと、この文書の整合を保ちます。
