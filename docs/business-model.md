# ONE EIGHTの事業モデル

## 現在の案内方針（2026年11月27日更新）

「ONE EIGHT」の読み方は「オンエイト」です。英表記はONE EIGHT、既存ロゴの英小文字oneightを維持します。提供の中心はWebサイト・Webアプリの制作と導入で、導入後の日々の運用は店舗が行います。継続的な伴走運用・改善やヒアリングコンサルを主サービスにはしません。過去のコンサル料金・返金制度を現在のサービスとして紹介せず、この文書では最新のモデルを説明します。過去の [検証記録](validation.md) は作業時点の履歴です。

主な対象は、地域の小さな小売店です。既存の飲食店・美容院・小売店・ネイルサロン・ヨガ教室という5業種の紹介は維持します。対象としての紹介であり、導入実績や顧客一覧として扱いません。他業種を対象外にする条件も追加しません。

表現・デザインは [デザインとコンテンツの考え方](design-and-content.md) を参照してください。

## Webサイト・Webアプリの制作・導入

主コピーは厳密に **「条件、追加費用なし。10000円のみ」** とします。これは基本のWebサイト・Webアプリ制作と導入が税込月額10,000円であることを伝えるものです。月額を大きく、初期費用0円を太字で示します。近くに **DBアップグレードは別途月額3,000円（税込）、追加カスタマイズは事前見積もりによる有料対応** と明記し、全追加作業が無料という意味に広げません。制作物に問題・不具合があれば無料で修正します。

| 項目 | 確認済みの案内 |
| --- | --- |
| サービス | お店専用のWebサイト・Webアプリ制作と導入 |
| 初期費用 | 0円 |
| お試し | 基本プランは0円で1か月お試し。初月の基本月額料金は0円 |
| 基本月額料金 | 2か月目から10,000円（税込） |
| 主コピー | 条件、追加費用なし。10000円のみ（基本制作・導入の説明） |
| DBアップグレード | アップグレード時に別途月額3,000円（税込） |
| 2か月目以降のアップグレード時の合計月額 | 基本月額10,000円＋DB月額3,000円＝13,000円（税込） |
| 追加カスタマイズ | 事前見積もりによる有料対応 |
| 制作物の問題・不具合 | 無料で修正 |
| 導入後の日々の運用 | 店舗が行う |

「0円」は初期費用と初月の基本月額料金に関する説明です。2か月目以降の基本月額、DBアップグレード費用、追加カスタマイズ有料を近接して示します。無期限無料や、基本制作・導入以外の全作業が無料という説明にはしません。

主コピーを無料解約、最低利用期間なし、自動更新なし、追加機能の無制限提供など、指示されていない条件へ広げません。制作する内容、お試しの開始日、継続・解約の方法は利用前に確認します。

## 制作・導入と、その後の対応

依頼するWebサイト・Webアプリの内容を確認し、制作して店舗への導入までを行います。予約・記録・お知らせ・新しいシステムはWebサイト・Webアプリの応用として扱い、依頼時に内容と範囲を確認します。各機能が完成済み・標準搭載とは断定しません。

導入後の日々の更新や利用は店舗が行います。制作物に問題・不具合があれば無料で修正し、新たな要望による追加カスタマイズは事前見積もりで有料対応します。無料修正を、追加機能や新しい制作の無制限無料提供とは説明しません。

## データベースのアップグレード

基本の制作・導入料金とアップグレード時の追加料金を区別します。主コピーや月額10,000円（税込）の近くに「DBアップグレード時は別途月額3,000円（税込）、2か月目以降のアップグレード時は合計月額13,000円（税込）」と「追加カスタマイズは事前見積もり・有料」を示します。

アップグレードが必要になる具体的な基準、開始時点、容量や利用件数の上限は、今回の指示では確定していません。自動アップグレードや無制限利用、アップグレード費用の初月無料などを根拠なく追加しません。初月のお試しは、初期費用と基本月額料金が0円という確認済みの範囲で説明します。

## 事業の姿勢

お店が依頼したいWebサイト・Webアプリの内容を確認し、AI／Codexと共通の仕組みを活用して制作・導入します。問い合わせは依頼内容を確認する入口とし、ヒアリングコンサルや伴走運用を主な提供価値に置きません。導入後は店舗が日々運用できる構成を目指します。

実家の和菓子屋という接点を課題理解の起点とし、学生としての柔軟さを大切にします。支援実績はこれからであり、導入件数・成功事例・改善数値や、存在しない法人格・人物プロフィールを創作しません。

## 運営上の検討事項

以下は運営設計の論点であり、新たな公開条件や顧客への約束ではありません。

- **初月終了時の採算**：標準構成では初期費用・初月の基本月額料金が0円です。制作・対応の範囲と継続率を踏まえて採算を確認します。新しい契約条件を追加するものではありません。
- **基本月額での対応範囲**：制作・導入内容を確認し、日々の運用は店舗が行うことを明確にします。制作物の問題・不具合は無料修正、追加カスタマイズは事前見積もり・有料です。未合意の即時対応は約束しません。
- **DBアップグレードの案内**：必要性、適用時点、追加月額3,000円（税込）と合計月額13,000円（税込・2か月目以降のアップグレード時）を利用者が理解できるよう整理します。

料金・条件の参照元は `src/data/site.ts` です。サイトの本文・料金表示・FAQと、この文書の整合を保ちます。
